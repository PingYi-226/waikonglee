Lattice-based cryptography rests on the hardness of finding short vectors in high-dimensional lattices. Schemes such as Kyber and Dilithium compute with polynomials in rings, and the number-theoretic transform turns their multiplication into pointwise products. On graphics processors the transform runs in thousands of threads at once; on microcontrollers every cycle and every byte of memory counts.

// Barrett reduction keeps coefficients small
int16_t barrett_reduce(int16_t a) {
  int16_t t;
  const int16_t v = ((1 << 26) + KYBER_Q / 2) / KYBER_Q;
  t = ((int32_t)v * a + (1 << 25)) >> 26;
  t *= KYBER_Q;
  return a - t;
}

Homomorphic encryption lets a server compute on data it cannot read. Bootstrapping, the step that refreshes a ciphertext's noise, dominates the cost; keeping a GPU busy through it is a matter of memory layout as much as arithmetic.

Deep inside

A link to this heading lands here, inside the tall section, not at its top.

Side-channel resistance asks that the time, power and electromagnetic traces of a computation say nothing about its secrets. Masking splits every secret into random shares; constant-time code removes branches and memory accesses that depend on secret data.

Deep learning on encrypted data combines both worlds: the network's layers become polynomial approximations, and the accelerator's job is to evaluate them fast enough to be useful.
